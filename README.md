# 🧑‍💼 Employee Table SQL Operations

This project showcases common SQL operations performed on an `employee` table including updates, queries, and analysis. It serves as a demonstration of database manipulation skills using **SQL** (Structured Query Language).

---

## 📁 Project Overview

The project includes:

- Creation of an `employee` table
- Insertion of employee records
- Data retrieval and filtering using `SELECT`
- Data update using `UPDATE`
- Additional SQL operations such as `JOIN`, `ORDER BY`, `GROUP BY`, and `DELETE`
